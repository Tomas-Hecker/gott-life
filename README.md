# Bücher von Tomas Hecker

Website zu den Büchern „Bis er es findet“ und „Darf ich dein Herz entzünden?“:
reines HTML mit einer `style.css`, keine Skripte, keine Cookies, nichts von fremden Servern.

## Seiten

- `index.html`: Startseite mit beiden Büchern, Perle, Angeboten für Gemeinden, Über Tomas
- `bis-er-es-findet/`: das neue Buch, dazu `vorwort.html` als Leseprobe
- `darf-ich-dein-herz-entzuenden/`: das erste Buch mit drei Gedichten als Leseprobe und Bestellung
- `hilfe.html`, `impressum.html`, `datenschutz.html`
- `fonts/` (EB Garamond, Inter; SIL Open Font License), `img/` (Umschläge), `favicon.svg`

## Veröffentlichen mit GitHub Pages

Im Repository unter Settings → Pages bei „Build and deployment“ die Quelle „Deploy from a branch“
wählen, Branch `main`, Ordner `/ (root)`. Die Datei `.nojekyll` sorgt dafür, dass GitHub die Dateien
unverändert ausliefert. Eine eigene Adresse lässt sich später unter „Custom domain“ eintragen.
